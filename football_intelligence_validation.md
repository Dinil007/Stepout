## MODULE OVERVIEW

### IntelligenceEngine (`app/analytics/intelligence_engine.py`)

**Purpose:** Transform raw analytics into actionable insights for coaches, scouts, and analysts

**Inputs:**
- `player_statistics.csv` - Per-player physical metrics
- `analytics.json` - Pipeline summary
- `pass_network.json` - Pass graph data
- `team_shape.json` - Team shape metrics
- `possession_summary.json` - Possession stats
- `territory_control.json` - Territory metrics
- `pressing_metrics.json` - Pressing stats
- `shot_events.json` - Shot data
- `xg_summary.json`, `xa_summary.json`, `xt_summary.json` - Expected metrics

**Outputs:**
- `player_performance.json` - Comprehensive per-player metrics
- `player_ratings.json` - Overall rating 0-10 with weights
- `team_insights.json` - Team strengths, weaknesses, tactical patterns
- `player_comparison.json` - Percentile rankings
- `match_summary.json` - Automated match analysis

**Integration:** Called in `scripts/run_match_analysis.py` during `stage_save_outputs()`

## FORMULA DOCUMENTATION

### MODULE 1 - PLAYER PERFORMANCE ENGINE

**Input:** `player_statistics.csv` (generated by PlayerStatisticsAggregator)

**Output Fields:**
```json
{
  "track_id": 1,
  "distance_m": 8500.0,
  "avg_speed_kmh": 22.5,
  "max_speed_kmh": 32.1,
  "sprint_count": 15,
  "high_intensity_distance_m": 2100.0,
  "acceleration_count": 45,
  "deceleration_count": 38,
  "work_rate_m_per_min": 95.3,
  "activity_index": 0.75,
  "ball_touches": 25,
  "pass_accuracy_pct": 82.5,
  "shot_accuracy_pct": 33.3,
  "xg": 0.35,
  "xa": 0.12,
  "xt": 1.45,
  "defensive_actions": 8,
  "heatmap_coverage_pct": 65.2
}
```

**Formulas:**
- `distance_m` = sum of all frame-to-frame displacements (meters)
- `avg_speed_kmh` = mean of instantaneous speeds (km/h)
- `max_speed_kmh` = max of instantaneous speeds (km/h)
- `sprint_count` = count of speed > SPRINT_THRESHOLD (default 25 km/h)
- `high_intensity_distance_m` = sum of distances where speed > RUN_THRESHOLD (default 20 km/h)
- `acceleration_count` = count of acceleration > 2.0 m/s²
- `deceleration_count` = count of deceleration < -2.0 m/s²
- `work_rate_m_per_min` = distance_m / (match_duration_minutes)
- `activity_index` = high_intensity_distance_m / distance_m
- `ball_touches` = count of frames where player is possessor
- `pass_accuracy_pct` = completed_passes / total_passes * 100
- `shot_accuracy_pct` = shots_on_target / total_shots * 100
- `xg` = sum of xG values from xGEngine
- `xa` = sum of xA values from xAEngine
- `xt` = sum of xT values from xTEngine
- `defensive_actions` = count of tackles + interceptions + pressures
- `heatmap_coverage_pct` = unique_bins_visited / total_bins * 100

### MODULE 2 - PLAYER RATING

**Formula:**
```
rating = (
    0.20 * passing_score
    + 0.20 * defensive_score
    + 0.20 * xg_xa_xt_score
    + 0.20 * movement_score
    + 0.20 * possession_score
) * 10
```

**Component Normalizations:**

1. **Passing (20%)**
   ```
   pass_score = min(max(pass_accuracy_pct / 100, 0), 1)
   ```

2. **Defensive (20%)**
   ```
   def_score = min(max(defensive_actions / 20, 0), 1)
   ```
   Max normalization: 20 defensive actions per match (elite level)

3. **xG/xA/xT (20%)**
   ```
   xg_score = min(max(xg / 0.5, 0), 1)
   xa_score = min(max(xa / 0.5, 0), 1)
   xt_score = min(max(xt / 2.0, 0), 1)
   xg_xa_xt_score = (xg_score + xa_score + xt_score) / 3
   ```
   Normalizations:
   - xG: 0.5 = world-class single-match total
   - xA: 0.5 = world-class single-match total
   - xT: 2.0 = world-class single-match total

4. **Movement (20%)**
   ```
   dist_score = min(max(distance_m / 12000, 0), 1)
   speed_score = min(max(max_speed_kmh / 35, 0), 1)
   sprint_score = min(max(sprint_count / 20, 0), 1)
   movement_score = (dist_score + speed_score + sprint_score) / 3
   ```
   Normalizations:
   - Distance: 12km = elite midfielder/defender
   - Speed: 35 km/h = Usain Bolt peak (absolute max)
   - Sprints: 20 = very high intensity match

5. **Possession Contribution (20%)**
   ```
   poss_score = min(max(ball_touches / 100, 0), 1)
   ```
   Normalization: 100 touches = dominant midfielder

**Output:** Rating 0.00 - 10.00 (rounded to 2 decimal places)

## METRIC VALIDATION

### Valid Ranges

| Metric | Valid Range | Unit | Validation Method |
|--------|-------------|------|-------------------|
| Player Rating | [0, 10] | score | Clamped by normalization |
| Distance | [0, 15000] | meters | Physical max ~14km per match |
| Avg Speed | [0, 35] | km/h | Human sprint max ~37 km/h |
| Max Speed | [0, 40] | km/h | Safety margin above 37 km/h |
| Sprint Count | [0, 50] | count | Physical max ~1 per 2 min |
| Pass Accuracy | [0, 100] | % | Clamped by normalization |
| xG | [0, 2.0] | count | World-class ~0.5 per match |
| xA | [0, 2.0] | count | World-class ~0.5 per match |
| xT | [0, 5.0] | count | World-class ~2.0 per match |
| Defensive Actions | [0, 50] | count | Physical max per match |
| Possession % | [0, 100] | % | Sum of both teams = 100 |
| PPDA | [0, 100] | ratio | Typical range 5-20 |
| Third Occupancy | [0, 100] | % | Sum of all thirds = 100 |
| Work Rate | [0, 200] | m/min | Elite ~120 m/min |

### Validation Checks Implemented

```python

    pct = (frames / total_possessor_frames) * 100

# 2. Normalization clamping
def norm(val, max_val):
    return min(max(val / max_val, 0), 1)

# 3. Empty data handling
if not performance:
```

## EDGE CASES

### Handled

1. **Empty player statistics:** `if not csv_path.exists(): return {}`
2. **Zero possession frames:** `if total_possessor_frames > 0 else 0.0`
3. **No pass events:** `if opp > 0 else 0.0` for PPDA
4. **Single player:** Percentile = 100.0 (only player)
5. **Missing CSV columns:** `row.get("field", default)`
6. **Zero maximum values in normalization:** `min(max(val / max_val, 0), 1)` handles max_val=0

### Not Handled

1. **Goalkeepers:** Treated same as outfield players in ratings
2. **Substitutions:** New track IDs treated as new players
3. **Red cards:** Player removal not adjusted
4. **Different positions:** No position-specific normalization
5. **Match context:** No adjustment for match importance, scoreline, time of goals

## KNOWN LIMITATIONS

### 1. Data Dependencies

The IntelligenceEngine depends on `player_statistics.csv` existing. If this file is missing (e.g., pipeline failure), the engine returns empty results.

### 2. Placeholder Values

- `central_play_pct` = 50.0 (requires pass lane analysis)
- `dangerous_possessions` = 0 (requires xG thresholding)
- `heatmap_coverage_pct` = 0 (requires pre-computed coverage)

### 3. Simplified Logic

- Team insights use simple heuristics (e.g., width > 50m = "High")
- Counter attacks approximated from possession chain length
- No context-aware adjustments (scoreline, time remaining)

### 4. No Position-Specific Ratings

All players use same normalization constants. A goalkeeper's 12km distance is exceptional; for a midfielder it's average.
